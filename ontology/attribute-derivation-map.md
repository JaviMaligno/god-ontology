# Attribute Derivation Map

This is the F1 control map for the transition from necessary agent to a fuller God-concept. It classifies prior work rather than re-arguing it. “Earned” means supported within the current architecture; it does not mean demonstrated independently of the project's premises.

## Classification key

| Classification | Meaning |
| --- | --- |
| Starting hypothesis | Introduced at an upstream junction and still carrying that burden |
| Constitutive | Part of the selected meaning of agentive sourcehood |
| Earned in the architecture | Follows from several current commitments taken together |
| Adopted extension | Deliberately added and defended beyond the minimum agent concept |
| Supported | Preferred but not entailed |
| Open/deferred | Not yet earned or deliberately postponed |
| Rejected inference | Must not be imported from an earlier attribute |

## Present stopping point

Conditional on provisional C04 and preferred C05, the current cumulative profile is:

> a necessary conscious and rational underived power-structured subject, preferred as the ultimate ground, capable of contingently actualizing a generative structure through originative existential power, knowing complete actuality and modal possibilities without temporal acquisition, standing in ontological priority to created spacetime, and capable of every independently eligible action licensed by the preferred ontology under explicit modal bridges. Created conscious agents are one embodied hylomorphic-organismic bearer whose absolute numerical identity can conditionally span a gappy life-history. Actual creation remains constitutively disjoint, while eligible non-depleting whole-presence and executive-mode constitution are retained as unexercised conditional capacities.

This is already more than an intermediary factory worker, because $G$ is preferred as the unique, physically immaterial, fundamentally non-spatial, minimally constitutively simple, ontologically omnipresent, ontology-relatively maximally powerful, and universally personally available ultimate ground and actualizer rather than a contingent operator inside a prior reality. It remains less than the God of full classical theism because absolute simplicity, immutability, goodness, universal exercised personal regard, and loving communion have not been earned, while unrestricted cross-ontology qualified omnipotence remains provisional.
