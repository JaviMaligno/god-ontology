# Provenance Checklist for the Literature Pass

**Prepared:** 2026-09-02 (S69 addendum). **Purpose:** every citation in the question-driven sessions was recorded from memory because the remote environment has no access to literature sites (plato.stanford.edu, philpapers.org, cambridge.org, doi.org, newadvent.org all unreachable through the proxy). The author will run the pass locally. Each row states the work as cited, the project claim it is attached to, and what has to be checked: that the work exists as cited (title, year, venue), that it says what the session attributes to it, and whether the attribution changes the classification in `novelty-and-precedent.md`. The trunk sessions (S30–S45) carry linked citations that were verified by the author at the time and are not repeated here.

Legend for the *check* column: **E** existence and bibliographic details; **A** attribution (does it say this?); **C** classification effect (established / synthesis / distinctive).
