# Session Records

Each substantial future discussion gets one dated file named `YYYY-MM-DD-short-topic.md`. A session record is a decision log, not a full transcript. Raw conversational material may be appended separately when useful.

Create new records from [TEMPLATE.md](TEMPLATE.md). Stable conclusions are promoted to `ontology/`; literature findings to `research/`; polished prose to `writing/`.
