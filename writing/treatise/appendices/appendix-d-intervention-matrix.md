# Appendix D — Intervention Compatibility Matrix

*First pass (S69, 2026-09-02). Hand-written from S04, S19, S35, S41–S45, S51, and S63. Each row is an intervention type; each column a question the ontology answers about it. “Free” means the affected token act can remain the creature's on the autonomy test (C36); “miracle” follows the definition of C43; “range” names the power result under which the type falls; “WFR” records whether the type can be a response to a condition manifested later in created time (C550–C551).*

## D.3 Response and time

| Case | Coherent? | Condition |
| --- | --- | --- |
| response manifested after the condition it answers | yes | covered by $HI_G$ (C417); the condition lies in the prefix |
| response manifested before a creaturely free act it answers | yes iff agent-neutral for that agent up to the act | WFR (C550–C551); no would-counterfactual used |
| response manifested before a natural condition it answers | yes iff the condition is causally independent of the response | WFR read causally |
| condition-sensitive policy over a life | yes iff the policy is not self-referential | fixed point well founded under WFR (C552); self-referential policies coincide with curation |
| “God changed the history” | no, as stated | creature-relative shorthand; an intervention is a constituent of the one history (C22, C417) |
